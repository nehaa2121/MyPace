IBPS SO IT OFFICER

IBPS (Institute of Banking Personnel Selection) recruits IT Officers (Scale-I) for Public Sector Banks such as:

  • Punjab National Bank
  • Bank of Baroda
  • Canara Bank
  • Indian Bank
  • Union Bank of India

An IT Officer is responsible for managing banking technology systems, networks, databases, cybersecurity, software support, and digital banking services.

Why this exam is good for you

As a BCA student who:
  • Likes coding
  • Wants an IT career
  • Wants a government/banking job
  • Is learning DBMS, OS, Networking, Cyber Security

This exam matches your background very well.

Eligibility

For IT Officer Scale-I, eligible qualifications generally include:

  • B.Tech/B.E. in CS/IT/Electronics-related fields
    • MCA
  • M.Sc IT/Computer Science
  • BCA with specified higher qualifications or recognized equivalent eligibility as per notification requirements. Always verify the latest notification.
Since you have completed BCA and are planning further studies (MCA), keep checking the official notification each year for exact eligibility wording.

Selection Process

Stage 1: Prelims

This is a qualifying exam.

Subject Questions Marks
English 50 25
Reasoning 50 50
Quantitative Aptitude 50 50

Total:

  • 150 Questions
  • 125 Marks
  • 120 Minutes
  • Negative Marketing: 0.25 per wrong answer

Stage 2: Mains

This is the most important stage.

Only Professional Knowledge (IT) is asked.

Questions Marks Time
60 60 45 minutes

The mains score is used for final selection.

Stage 3: Interview

Interview generally tests:

  • IT concepts
  • Banking awareness
  • Communication skills
  • Project knowledge
  • Current technology trends

Final merit is based mainly on Mains and Interview performance.

Actual Work of an IT Officer

After selection, you may work in:

Database Administration

  • Oracle
  • SQL Server
  • Database backup
  • Database security

Network Administration

  • Routers
  • Switches
  • VPN
  • Firewalls

Cyber Security

  • Security monitoring
  • Threat detection
  • Incident response

Banking Software Support

  • Core Banking Systems
  • ATM software
  • Mobile Banking applications

Server Management

  • Windows Servers
  • Linux Servers

Digital Banking Projects

  • UPI
  • Internet Banking
  • Mobile Banking
