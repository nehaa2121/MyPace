NIC Roadmap

BCA → MCA → GATE CSE → NIC Scientist-B

Phase 1: During MCA (1st year)

Study these computer science subjects thorough:

  • Data Structures & Algorithms
  • Operating Systems
  • Database Management Systems (DBMS)
  • Computer Networks
  • Object-oriented Programming (Java/C++)
  • Software Engineering
  • Discrete Mathematics
  • Digital Logic
  • Computer Organization & Architecture

Practice:

  • 2-3 DSA Problems daily
  • SQL every week
  • Build 2-3 Projects

Phase 2: GATE Preparation (Start in MCA 1st year)

Study GATE CSE Subjects:

  • Programming & DSA
  • DBMS
  • OS
  • Computer Networks
  • Computer Organization
  • Digital Logic
  • Theory Of Computation
  • Compiler Design
  • Discrete Mathematics
  • Discrete Mathematics
  • Engineering Mathematics

Target:

  • GATE Score: 700+
  • Higher Scores improves your chances of being shortlisted

Phase 3: Apply For NIC

When the recruitment notification is released:

  • Apply Online
  • Submit Your valid GATE Score
  • If shortlisted, attend document verification and interview.

Skills

  • Java
  • Python
  • SQL
  • Linux
  • Git & GitHub
  • HTML, CSS, JS
  • Basic Cloud Concepts
  • Problem Solving
