Indian Space Research Organisation (ISRO) - IT Roles

If you love computers, coding, cybersecurity, software developemnt, and space technology, ISRO is obe of the most exciting government organizations to work for.

What Do IT Professionals Do in ISRO?

ISRO needs computer engineers and IT professionals for:

Software Development

  • Satellite control software
  • Mission monitoring systems
  • Launch vehicle software
  • Ground station applications

Cyber Security

  • Protecting satellite networks
  • Securing mission-critical systems
  • Security adults
  • Incident response

Database Administration

  • Mission data management
  • Scientific data storage
  • Data processing systems

Network Administration

  • Communication networks
  • Data centers
  • Secure internal networks

AI & Data Analytics

  • Satellite image
  • Machine Learning
  • Remote sensing applications

Cloud & High-Performance Computing

  • Supercomputing
  • Big Data processing
  • Scientific simulations

Eligibility

For Scientist/Engineer (Computer Science), recruitment generally requires:

  • B.E/B.Tech in Computer Science, IT, Computer Engineering, or related discipline with required marks as specified in the notification.

For BCA students, direct Scientist/Engineer eligibility is usually not available. An MCA can significantly improve eligiblity for various technical opportunities, depending on recruitment rules.

Always check the latest ISRO notification.
