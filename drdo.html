Defence Research and Development Organisation (DRDO) IT Roles

DRDO is India's premier defense research organization. If you join in an IT-related role, you may work on:

  • Cyber Security
  • Artificial Intelligence
  • Software Development
  • Data Analytics
  • Network Security
  • Embedded Systems
  • Supercomputing
  • Secure Communication Systems
  • Defence Applications

DRDO develops technology for the Indian Armed Forces and defense sector.

Main IT Posts in DRDO

1. Scientist 'B' (Computer Science)

This is the most prestigious entry-level technical position.

Work

  • Software development
  • AI and Machine Learning
  • Cyber Security research
  • Network Security
  • Defence software systems
  • Simulation systems
  • Data processing

Salary

  • Basic Pay: 56,100
  • Gross Salary: often Rs.80,000-Rs.1,00,000+ depending on allowances and location.

Eligibility

Typically requires:

  • First-class B.E./B.Tech in Computer Science or equivalent discipline
  • Valid GATE score in CS/IT for Computer Science Scientist-B recruitment streams.

2. Senior Technical Assistant-B (STA-B)

A strong option for computer graduates.

Work

  • System Administration
  • Network Management
  • Database Support
  • Software Maintenance
  • Technical Support

Salary

Pay Level-6:

  • Approximately ₹35,400 basic plus allowances.

Eligibility

For Computer Science disciplines, notifications have included:

  • B.Sc. Computer Science
  • Diploma in Computer Science/IT/Engineering-related fields (depending on the specific recruitment notification).

3. Cyber Security Roles

DRDO laboratories work on:

  • Ethical Hacking
  • Malware Analysis
  • Cryptography
  • Digital Forensics
  • Security Auditing
  • Secure Defence Networks

These positions are usually recruited through Scientist or technical cadres rather than a separate "Cyber Security Officer" exam.

For You (BCA + MCA Aspirant)

A realistic path could be:

BCA - MCA - GATE CS preparation - DRDO Scientist-B

At the same time, prepare for:
