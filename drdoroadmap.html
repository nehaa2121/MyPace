TARGET 1: DRDO SCIENTIST 'B'

This should be your dream target

The recruitment of scientists is handled by DRDO's Recruitment & Assessment Centre (RAC).

For Computer Science, your preparation should be at approximately:

GATE CS + Strong CS fundamentals + technical interview level.

PHASE 1 - PROGRAMMING

2-3 months

You already study Python, so keep it.

Python

Learn:

  • Variables
  • Data types
  • Conditions
  • Loops
  • Functions
  • Lists
  • Tuples
  • Sets
  • Dictionaries
  • Strings
  • File handling
  • Exception handling
  • Modules
  • OOP

Then add:

C/C++

This is important for a serious Computer Science competitive-exam preparation.

Learn:

  • Pointers
  • Arrays
  • Strings
  • Structures
  • Functions
  • Memory
  • Classes
  • OOP
  • STL basics

Your priority:

Python → C/C++ → DSA

PHASE2 - DATA STRUCTURES & ALGORITHMS

4-5 months

This is one of the biggest parts of your DRDO/GATE preparation.

Study:

Basic

  • Arrays
  • Strings
  • Linked Lists
  • Stack
  • Queue
  • Hashing

Advanced

  • Trees
  • BST
  • Heap
  • Graphs
  • Trie basics

Algorithms

  • Searching
  • Sorting
  • Recursion
  • Backtracking
  • Greedy
  • Divide & Conquer
  • Dynamic Programming basics

Complexity

You Must Understand:

Big-O

For example

O(1)

O(log n)

O(n)

O(n log n)

O(n²)

PHASE 3 - DBMS

2-3 months

You should become very strong here.

Study

  • ER model
  • Relational model
  • Keys
  • Functional dependencies
  • Normalization
  • SQL
  • Joins
  • Subqueries
  • Views
  • Indexes
  • Transactions
  • ACID properties
  • Concurrency control
  • Serializability
  • Recovery

Practice SQL regularly.

Since you are already learning database concepts, this will also help with:

MCA + GATE + NIC + C-DAC + IBPS SO + DRDO.
